# 💰 Monthly Expense Tracker

A modern and responsive **Monthly Expense Tracker** web application that helps users efficiently manage their daily expenses, monitor spending habits, and gain insights into their financial activities through an intuitive dashboard.

## 🌐 Live Demo

🔗 **Website:** https://sahilprojects676.github.io/MonthlyExpensetracker/

---

## 📖 About the Project

The Monthly Expense Tracker is designed to simplify personal finance management by allowing users to record income and expenses, categorize transactions, and visualize spending patterns.

The project focuses on providing a clean user interface, responsive design, and an easy-to-use experience for tracking monthly budgets.

---

## ✨ Features

* 📊 Dashboard with expense overview
* 💸 Add, edit, and delete expenses
* 🏷️ Expense categorization
* 📅 Monthly expense tracking
* 📈 Spending analytics
* 🤝 Borrowing (Udhari) Khata to track lent & borrowed dues with settlement
* 📱 Fully mobile-responsive design
* 💾 Local data storage
* ⚡ Fast and lightweight interface

---

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript
* Chart.js
* Local Storage API
* Git & GitHub Pages

## 📌 Why This Project?

Many users value applications that prioritize privacy and local data storage over unnecessary complexity.
